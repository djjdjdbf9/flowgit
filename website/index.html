          TECHNICAL SPECIFICATIONS
          
ENGINEERED FOR WORKFLOW VELOCITY

          

            Every component in FlowGit is designed around deterministic Git execution, strict context isolation,
            and terminal-grade monospaced ergonomics.
          

        


        

          
          

            
// 01 — VISUAL ARCHITECTURE

            
Signature Blueprint Git Graph

            

              Infinite canvas pan-and-zoom DAG renderer. Computes real topological ancestry, non-overlapping lane columns,
              and parent-child cubic Bezier splines. Never get lost in sprawling branch merges again.
            

            
    
              
  • Infinite dot-grid canvas (0.25x to 3.0x zoom)
    • 
              
  • Live minimap radar with viewport box tracking
    • 
              
  • Instant jump-to-HEAD and filter search
    • 
            

          


          
          

            
// 02 — PROCESS SECURITY

            
Zero Shell Concatenation

            

              Direct binary invocation via safe argv arrays (spawn('git', [args])).
              Eliminates shell escape vulnerabilities, handles spaces and unicode filenames securely, and scrubs credentials before logging.
            

            
    
              
  • Context isolation with strict IPC channel guards
    • 
              
  • Automatic token & HTTP basic auth redaction
    • 
              
  • Multi-stage Windows Git binary detector
    • 
            

          


          
          

            
// 03 — HIGH PERFORMANCE CACHING

            
SQLite WAL Persistence

            

              Instantaneous startup and sub-second repo switching. FlowGit persists repository records, pinned workspaces,
              and graph coordinates in an embedded SQLite engine with Write-Ahead Logging (WAL).
            

            
    
              
  • Zero cold-start lag on 100k+ commit repositories
    • 
              
  • Atomic disk commits with zero file corruption
    • 
              
  • Zero cloud dependency — 100% local data
    • 
            

          


          
          

            
// 04 — STAGING & COMMITS

            
Porcelain-v1 Index Staging

            

              Deterministic file staging based directly on Git's porcelain status format.
              Atomic file actions with confirmation safeguards for destructive operations.
            

            
    
              
  • Clear Staged, Unstaged, Untracked & Conflicted separation
    • 
              
  • Amend commit flag & live 72-character counter
    • 
              
  • Selective hunk staging and safe worktree discard
    • 
            

          


          
          

            
// 05 — COMPARISON ENGINE

            
Unified & Split Diff Viewer

            

              Terminal-grade diff parsing engine with additions/deletions highlighting, line numbering for both revisions,
              and intelligent context folding for unchanged code.
            

            
    
              
  • Side-by-side split & unified inline comparison modes
    • 
              
  • Protective threshold for binary and large files
    • 
              
  • Design-system safe muted color accents
    • 
            

          


          
          

            
// 06 — BRANCHES & SYNC

            
Branch Matrix & Stash Sync

            

              Complete local and remote-tracking branch management with upstream sync indicators (↑ ahead / ↓ behind),
              annotated tags, and untracked-file stash operations.
            

            
    
              
  • Safe push with force-with-lease protection
    • 
              
  • Network error classification with actionable recovery
    • 
              
  • Instant stash preview, pop, apply, and drop
    •
